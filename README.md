# Integrated Delivery Portal — Frontend

The frontend of the Integrated Delivery Portal, built with React and TypeScript. It provides interfaces for public users, clients, and administrators and communicates with the backend through REST APIs.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Axios
- TanStack React Query
- React Router
- React Hook Form & Zod
- Recharts
- Framer Motion
- Lucide React

## Main Features

- User authentication and email verification
- Client and admin dashboards
- Company and user management
- Delivery and customer management
- API key management
- Reports and analytics
- MFA and password recovery
- Responsive light/dark interface
